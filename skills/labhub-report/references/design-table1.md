# 實驗設計：先畫 Table 1（第 2 站）

來源：`guides/experiment_design/design_table1.md` v1.5。教授挑定 card 之後、**寫任何程式之前**。

## 鐵律

**沒有教授審核紀錄的一行之前不寫程式。** 這是鐵律，不是建議。設計文件完成只是起點，必須等教授在審核紀錄留下一行才能動工。

## 輸出檔案

`design/〔題目〕_design_〔日期〕.md`，內含：
- Table 1 空表
- 消融表
- method figure
- 論文骨架
- 一頁決策紀錄（一句話主張 + 審核紀錄區）

## Table 1 數值來源代碼（固定四種）

| 代碼 | 意義 |
|---|---|
| C | Cite — 引用別人論文的數字 |
| R | Run — 自己重跑得到的數字 |
| O | Ours — 自己方法的數字 |
| — | 還沒有數字（空格） |

每一格填入數字時必須標代碼，讓教授一眼看出「這格可信度是什麼層級」。

## 長論文最低要求

長論文（投 ML 主會類）至少要 **2 個資料集**，不能只靠單一資料集撐主張。

## 公平比較四問（和論文報告第9頁同一套，提前自問）

- 同 backbone？
- 同資料？
- baseline 重跑還是引用？
- 多 seed？

## Seed 數與顯著性

**依目標會議、資料量、算力決定，不要自己套規則。** 這格留白問教授（§3.3 但書）。

## 自建資料的限制

**不到 4 個月不開新蒐集。** 截稿日倒推，時間不夠就不要提自建資料的選項。

## AI 禁寫部分

- 一頁決策紀錄的「一句話主張」必須使用者自己寫
- Table 1 砍不砍格由教授決定，不是 AI 猜
- 最強公開 baseline 跑不動要不要降一層——要在論文裡明說，由教授決定

## 要問教授的事

| 問題 | 為什麼 |
|---|---|
| 這個題目和 lab 既有工作有沒有重疊？ | 避免和同學做到同一格 |
| seed 數與顯著性怎麼做？ | 依會議/資料量/算力定，不自己套規則 |
| 最強公開 baseline 跑不動，可以降一層嗎？ | 要在論文明說，教授決定 |
| 自建資料非做不可嗎？截稿前來得及嗎？ | 不到4個月不開新蒐集 |
| Table 1 審過了嗎？ | 審核紀錄沒教授那一行之前不寫程式 |

## 怎麼核對

1. Table 1 每一格的代碼（C/R/O/—）都標了
2. 長論文確認至少 2 個資料集
3. 公平比較四問都有答案（或標「待確認」）
4. 決策紀錄的審核欄位空著，等教授那一行，沒有就不開始寫程式
5. 一句話主張是使用者自己寫的，不是 AI 代寫
