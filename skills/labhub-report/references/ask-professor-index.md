# 要問教授的事：總表

來源：`conventions/ask_professor.md` v1.1。用途：一次看到哪些事永遠不要自己猜。問之前先準備好東西（畫好的表、跑過的數字、寫好的card），不要空手問。

## 永遠由教授決定的事

題目、資料、GPU、目標會議與截稿日、baseline降不降層、Table 1砍不砍格、card過不過；產學的需求變更、交付內容、發表限制。

**skill 遇到這些問題，一律在模板裡留白或寫「待教授決定／待教授確認」，不自己填一個合理猜測。**

## 分站問題清單

| 階段 | 問題 |
|---|---|
| 進實驗室第一週 | partner是誰？repo命名？GPU型號數量怎麼共用？lab慣用工具鏈/backbone/現成checkpoint？lab有哪些語料？group meeting時間與論文報告輪序？ |
| 第0站跑完選路線前 | Round1報告§9的5-8個問題；選哪條路線；目標會議與截稿日 |
| 出題（1b） | 方向和lab其他同學重疊嗎？教授當時怎麼想到這方向？退回代碼是哪一個？要不要先做最小驗證？ |
| 實驗設計（第2站） | 題目和lab既有工作重疊嗎？seed數與顯著性怎麼做？最強baseline跑不動能降層嗎？自建資料來得及嗎？Table1審過了嗎？ |
| 復現與實驗（第3+4站） | 復現超過3週對不上能降baseline嗎？錯誤類別分法可以嗎？填不完Table1砍哪幾格？卡超過3工作天先partner再教授 |
| 每週（第5站） | Issue摘要的回饋對嗎？投影片格式要改嗎？ |
| 論文報告 | 這篇值得報嗎？方法節解釋對不上哪個對？「審稿人會問」問得對嗎？這篇要變成card嗎？ |
| 產學計畫 | repo放哪叫什麼誰有權限？測試資料放哪台機器哪路徑？交付日期與里程碑？發表限制三件？資料太少切不出驗收集怎麼辦？門檻產業方給不出來怎麼定？需求變更接不接？會後紀錄誰寄？未發表方法/checkpoint要不要交？東西能不能給AI處理？ |

完整表格與「為什麼」「出處」欄位見原始檔 `conventions/ask_professor.md`；skill 執行中若遇到這類問題，直接引用這份清單提醒使用者去問，不要代答。
