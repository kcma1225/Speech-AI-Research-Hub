## 問題（Problem）

![](diagrams/diagram-a87691e59085.svg){.hub-diagram fig-align="center" fig-alt="diagram" data-font="26"}

::: {.takeaway}
不需重新訓練模型，讓使用者提供的 hotwords 更容易被正確辨出
:::

::: {.notes}
串流 ASR 採即時解碼，對人名、課程名詞這類罕見詞特別容易誤認，因為這些詞在訓練資料中出現得少，模型難以靠語言模型先驗補救。這也是本簡報要處理的核心問題：罕見詞錯誤在串流場景下尤其明顯。圖的上方是現況：使用者說出人名或課程名詞，串流 ASR 輸出誤認的詞。下方是我們的目標：把使用者提供的 hotwords 清單透過 hotword biasing 送進解碼，讓這些詞被正確辨出。關鍵限制是不需重新訓練整個模型，只在既有模型上達成改善。
:::

## 淺層融合（Shallow fusion）

![](diagrams/diagram-db2ff8d222e9.svg){.hub-diagram fig-align="center" fig-alt="diagram" data-font="20.3"}

::: {.takeaway}
無需訓練、可用於任何 decoder；但讀音相近的詞有誤觸發（false trigger）風險
:::

::: {.notes}
淺層融合（Shallow fusion）是最簡單的基線（baseline），而且可以搭配任何解碼器（decoder）使用。如圖所示，它在 beam search 過程中查詢 hotword 前綴樹（prefix tree），對延伸樹的候選假設給予加分，讓包含 hotword 的路徑更容易勝出。此方法無需訓練即可使用，但讀音相近的詞容易被誤觸發（false trigger），這是它最主要的風險。
:::

## 深層上下文（Deep context, CLAS）

![](diagrams/diagram-1dfafb964fc8.svg){.hub-diagram fig-align="center" fig-alt="diagram" data-font="20.3"}

::: {.takeaway}
聯合訓練；bias 清單超過數百個片段時，準確率會下降
:::

::: {.notes}
CLAS 以端對端方式學習上下文 biasing。如圖所示，它為每個 bias 片段產生 embedding，並在 decoder 端對這些片段做 attention，把情境資訊注入解碼。訓練採聯合訓練的方式進行，因此 CLAS 需要含有 bias 清單的訓練資料。但當 bias 清單超過數百個片段時，準確率會下降。
:::

## 情境式 adapters（Contextual adapters）

![](diagrams/diagram-0c93d52ea954.svg){.hub-diagram fig-align="center" fig-alt="diagram" data-font="20.5"}

::: {.takeaway}
只訓練一個小型 adapter；訓練成本低，基礎模型維持不變
:::

::: {.notes}
對我們的設定來說，adapters 特別有吸引力，因為 Zipformer 基礎模型完全凍結、不需更新。如圖所示，只有插在 transducer 上的小型 adapter 是可訓練的：它讀取 bias 清單來提供情境資訊，再回饋給凍結的 transducer。由於基礎 transducer 維持不變，訓練成本相當低。基礎模型的參數保持原樣，情境調整全部交給這個小型 adapter 完成。
:::
