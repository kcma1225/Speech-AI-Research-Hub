## 問題定義

![](diagrams/diagram-54c9a0407362.svg){.hub-diagram fig-align="center" fig-alt="diagram" data-font="20.9"}

- 背景：E2E ASR 偏向訓練詞彙，熱詞常到推論時才出現
- 已從課程錄音整理 320 個專有名詞作 bias list
- 進度位置：目前在「題目發想」階段

::: {.takeaway}
不重訓模型，讓推論時才出現的人名與課程術語被正確辨識
:::

::: {.notes}
我們的研究問題：在 Zipformer 加 RNN-T 的串流語音辨識中做動態熱詞偏置（contextual biasing），過程中不重新訓練整個模型，目標是讓人名與課程術語更容易被辨識，里程碑是 ICASSP 2027 投稿（預計 2026-11-15）。背景方面，end-to-end ASR 的輸出偏向訓練詞彙，人名、內部術語這類熱詞常常到推論時才出現，所以辨識效果不佳（文獻回顧 2026-10-24）。素材已經備妥：從課程錄音整理出 320 個專有名詞作為 bias list（週會筆記 2026-10-20）。整體進度是題目發想 → 文獻探討 → 實驗 → 撰寫 → 投稿/口試，目前位於「題目發想」。圖上凍結的 Zipformer + RNN-T 代表主模型不動，強調色的動態偏置模組是我們要設計的核心；至於熱詞資訊怎麼注入，下一頁會比較幾條技術路線。
:::

## Idea 或架構

![](diagrams/diagram-607ee0c7b725.svg){.hub-diagram fig-align="center" fig-alt="diagram" data-font="26"}

:::: {.columns}
::: {.column width="50%"}
### Shallow fusion：解碼時加分

- 免訓練，對熱詞 trie 加分
- 串流下易誤觸發
:::
::: {.column width="50%"}
### Deep biasing：模型內接熱詞

- CLAS：attention 接解碼器
- Contextual adapters：凍結主模型
:::
::::

::: {.takeaway}
待確認：Zipformer 哪一層注入？熱詞清單變大時的效率？
:::

::: {.notes}
這頁把調研看到的四條技術路線分成兩大類：圖左是解碼時加分的 shallow fusion，圖右是把熱詞接進模型內部的 deep biasing 路線——兩張圖的差別就在注入位置：shallow fusion 是在解碼階段外加分數，deep biasing 則在模型內部、解碼器之前注入熱詞資訊。Shallow fusion 在解碼時對熱詞字首樹（trie）加分，不需訓練就能上線，但可能誤觸發（[@zhao2019shallow]）——我們的串流基線 lookahead 只有 320 ms，誤觸發率是老師指定的評估指標之一。CLAS／Deep context 用 attention 把熱詞嵌入接到解碼器，需要與 ASR 模型聯合訓練（[@pundak2018deep]）；週會筆記也記到熱詞清單一大（> 300 個）時 CLAS 的注意力會分散、罕見詞召回率下降。Contextual adapters 則是凍結主模型、只訓練小型 adapter（[@sathyendra2022contextual]）；Adaptive biasing 是在串流 transducer 上依情境開關偏置（[@xu2023adaptive]），對我們的串流場景是候選方案。待確認的架構問題有兩個：這些方法在 Zipformer 的哪一層注入熱詞資訊，以及熱詞清單變大時的效率（調研筆記 2026-10-24）——目前清單已有 320 個專有名詞，這會直接影響方法挑選。
:::

## 本週關鍵結果

![](diagrams/diagram-fe1b433b1146.svg){.hub-diagram fig-align="center" fig-alt="diagram" data-font="20.9"}

![](charts/chart-b008b8a5a64d.svg){.hub-chart fig-align="center" fig-alt="CLAS 相對 shallow fusion 的最大 WER 改善" data-font="16"}

::: {.takeaway}
基線與熱詞素材就位；文獻顯示熱詞偏置收益可達 68%（Pundak et al., Interspeech 2018）
:::

::: {.notes}
本週兩項關鍵素材都到位了（上方三張卡片）。第一，已在 icefall 上跑通 Zipformer 串流 RNN-T 基線，AISHELL-1 dev CER 為 5.1%（週會筆記 2026-10-20），這是後續所有偏置實驗的比較基準。第二，從課程錄音整理出 320 個專有名詞的熱詞清單，涵蓋目標場景中最容易辨錯的人名與術語。連同其他筆記，本週共完成四份筆記（週會筆記 2026-10-20；筆記清單 2026-10-24）。文獻錨點方面，下方的長條圖整理了 Pundak 等人提出的 CLAS 結果：在數百個情境詞組的情境下，相對 shallow fusion 基準的 WER 最多改善 68%（Pundak et al., Interspeech 2018，Abstract），顯示熱詞偏置一旦做對，收益空間相當可觀。基線與熱詞素材就位後，就能在同一份清單上開始比較 shallow fusion 與 neural biasing 的表現。
:::
